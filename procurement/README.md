# Execution-trace renewal — vendor comparison (2026 cycle)

We are renewing one upstream vendor for the execution-trace programme.
Quotes sit in `quotes/` one file per supplier, each in the supplier's
local currency.  Compare annual cost in HKD using the finance desk
bulletin in `rate-bulletin.md`.

The selected vendor's corpus becomes the upstream for both registry
datasets (`exec-trace-raw` and `exec-trace-curated`), so the licence
declared on that upstream card applies to both cards.

Vendor cards are mirrored in the vendor-cards repository.
